# おさんぽビンゴ グロース／マーケティング計画

対象プロダクト: https://osanpobingo-battle.com （PWA・インストール不要・無料）
目的: プレイ人数を増やす。特に「1人が誘うと3〜5人が遊ぶ」構造をつくる。

---

## 0. 前提整理（現状の強みと弱み）

**強み**
- インストール不要・無料・登録不要 → 参加障壁がほぼゼロ。招待が刺さりやすい。
- 合言葉（最大5文字）で同じお題プールを共有 → 招待の摩擦が小さい。
- 写真＋バトルモード → 「投稿したくなる絵」が自然に生まれる。
- GA4導入済み（`game_start` / `bingo_achieved` / `photo_saved` / `shared_to_sns` / `card_saved` / `game_end`）。

**弱み（伸ばす余地）**
- 招待が「合言葉を口頭／手打ちで伝える」前提。URLに合言葉を載せた招待リンクがない。
- `game.html` のOGPが弱い（`og:url` なし、`twitter:title` / `twitter:description` なし、`og:image` が相対パス）。SNSでシェアされた時のカードが本気になっていない。
- サイトのインデックス対象ページが4本のみ。検索流入の受け皿（お題図鑑・遊び方・季節版）がない。
- 「継続して遊ぶ理由」（今週のカード等）が弱い。

## 1. ターゲットとメッセージ

| 優先 | ターゲット | 刺さる価値 | 一言メッセージ |
|---|---|---|---|
| ★1 | 小学生以下の子を持つ親（休日の外出ネタ探し） | 子どもが自分から歩く／写真が思い出になる | 「"歩こう"が要らなくなる散歩」 |

| ★4 | 友人グループ・カップル（アクティビティ探し） | バトルモードの競争性 | 「散歩を対戦ゲームにする」 |

コアメッセージ（全チャネル共通）: **「いつもの散歩が、宝さがしになる。アプリ不要・無料・合言葉ひとつ。」**

## 2. KPI設計

North Star: **週あたりのゲーム開始数（`game_start`）**

| 階層 | 指標 | 現状計測 | 追加で必要 |
|---|---|---|---|
| 獲得 | LP→ゲーム開始 CVR | GA4 | LPのCTAクリックイベント |
| 体験 | ビンゴ達成率（`bingo_achieved` / `game_start`） | ✅ | — |
| 拡散 | シェア率（`shared_to_sns` / `game_end`） | ✅ | 招待リンク経由の流入計測（`?ref=invite`） |
| 招待 | K係数 = 1プレイヤーあたりの招待経由新規 | ❌ | 招待リンク発行イベント + 着地イベント |
| 継続 | 7日／28日リピート率 | 要設定 | GA4のユーザースコープ |

**90日目標の目安**: 週次 `game_start` 3倍、シェア率 10%以上、招待経由流入が全流入の20%以上。

## 3. プロダクト内グロース施策（最優先・実装タスク）

マーケの費用対効果はここが一番高い。広告より先にこれ。

### P0（すぐやる）
1. **招待リンク**: `game.html?room=ABCDE&level=normal` で合言葉と難易度をプリセット。
   - 「みんなで遊ぶ」作成後に「招待リンクをコピー／LINEで送る」ボタンを出す。
   - 受け取り側は開くだけで同じ卓に入れる（手打ちゼロ）。
   - リンクに `?ref=invite` を付与しGA4で招待経由を計測。
2. **OGPの本気化**（`game.html`）: `og:url` 追加、`og:image` を絶対URLに、`twitter:title` / `twitter:description` を追加。招待リンクがLINE/Xで貼られた時のカードがそのまま広告枠になる。
3. **シェア文言のA/Bと導線強化**: 現状 `おさんぽビンゴで遊んだよ～！ #おさんぽビンゴ #散歩 #ビンゴ`。
   - 結果に応じて可変に（例: 「25マス中18個みつけた！ダブルビンゴ🎉」）。数字が入ると反応率が上がる。
   - 結果画面のシェアボタンを最上部・最大サイズに。
4. **PWAインストール訴求**: 2回目のプレイ終了時に「ホーム画面に追加すると1タップで遊べます」を1度だけ表示。

### P1（1〜2ヶ月）
5. **今週のお題カード**: 週替わりの固定シード（全員同じ盤面）＋ハッシュタグ。継続とSNS上の会話を同時に作る。
6. **季節・地域テーマ**: 「夏休み版」「雨の日版」「海版」「商店街版」。テーマごとにLPを持てるのでSEO資産にもなる。
7. **達成カードのデザイン強化**: 保存画像に日付・歩いた場所名・見つけた写真のコラージュ。「思い出として残る」＝保存＆共有動機。
8. **ファミリーモード導線**: 「親子で遊ぶ」プリセット（かんたん＋写真ON＋フリーマス3）をワンタップで。

## 4. チャネル別プラン

### 4-1. SNSオーガニック（主戦場）

| チャネル | 使い方 | 投稿頻度 |
|---|---|---|
| X | 「今週のお題カード」画像、プレイヤーの投稿RP、季節ネタ | 週3 |
| Instagram（リール） | 15秒「散歩がゲームになる瞬間」動画。子ども・犬が主役 | 週2 |
| TikTok | 「親が"歩こう"って言わなくなる方法」系フック | 週2 |
| YouTube Shorts | リール流用 | 週2 |

**動画の型（使い回し可）**
1. 悩みフック（0-2秒）: 「子どもが散歩について来ない」
2. 提示（2-6秒）: スマホ画面でビンゴカード
3. 実演（6-20秒）: 街でお題を見つける→タップ→写真
4. 結末（20-28秒）: BINGO演出＋達成カード
5. CTA: 「"おさんぽビンゴ"で検索／アプリ不要」

**ハッシュタグ**: `#おさんぽビンゴ` を公式タグに統一（既にシェア文言側は統一済み）。UGCはすべてこのタグに集約し、公式アカウントで毎週まとめて紹介。

### 4-2. コミュニティ／口コミ
- **学童・児童館・子育て支援センターへの持ち込み**: 「準備ゼロのレク」としてA4の遊び方PDFを配布。印刷用PDFを `docs/` に用意する。
- **保育園・小学校のPTAイベント**: 合言葉を配るだけで100人規模が遊べる点を訴求。
- **地域の商店街・観光協会**: 「商店街ビンゴ」カスタム版。フリー入力マスで地域のお題を仕込める点が営業材料。
- **犬の散歩コミュニティ／ドッグラン**: 「わんさんぽビンゴ」テーマ。

### 4-3. アーンドメディア（無料掲載狙い）
- 子育て系メディア（コズレ、いこーよ、ハピママ等）に「無料・登録不要の外遊びアプリ」としてプレスリリース。
- Webアプリ紹介系（窓の杜、はてなブックマーク、ProductHunt日本枠）に投稿。
- 個人開発系コミュニティ（Zenn / note / X の個人開発クラスタ）に開発記を投稿 → 技術文脈から一次拡散を取る。

### 4-4. SEO（中長期の土台）
現状インデックスは4URL。以下を増設し、`sitemap.xml` に追加する。

| 新規ページ | 狙うクエリ |
|---|---|
| `/howto`（遊び方・完全ガイド） | 散歩 ビンゴ 遊び方 |
| `/topics`（お題図鑑・全お題一覧） | 散歩 ビンゴ お題 / ネタ |
| `/kids`（親子で遊ぶ） | 子ども 散歩 飽きる / 外遊び アイデア |
| `/print`（印刷して遊ぶ紙版・PDF配布） | 散歩 ビンゴ 印刷 無料 |
| `/event`（学校・イベント向け） | レクリエーション 屋外 準備なし |

`topics.js` に大量のお題データがあるので、お題図鑑ページは自動生成できる＝低コストで大量のロングテール獲得が可能。**ここは費用対効果が最も高いSEO施策。**

### 4-5. 有料広告（最後・小額から）
オーガニックとプロダクト内施策が回り始めてから。
- まずは月1〜3万円でMeta広告（配信対象: 未就学児〜小学生の親／犬の飼い主）。
- 動画クリエイティブは4-1で当たった投稿をそのまま転用。
- 目標CPA: 1ゲーム開始あたり50円以下。超えるなら止めてオーガニックに戻す。

## 5. 90日ロードマップ

**Month 1 — 基盤づくり（拡散する準備）**
- P0の実装4件（招待リンク、OGP、シェア文言、PWA訴求）
- GA4の招待計測・リピート計測を追加
- 公式X / Instagram アカウント開設、`#おさんぽビンゴ` の運用開始
- 印刷用PDFと「遊び方ガイド」ページを公開

**Month 2 — 拡散の点火**
- 短尺動画を週4本ペースで投稿（型は4-1）
- お題図鑑ページを `topics.js` から自動生成して公開
- プレスリリース配信＋子育てメディアへの個別打診
- 学童・児童館5箇所に持ち込みテスト

**Month 3 — 増幅と最適化**
- 「今週のお題カード」開始（継続導線）
- 季節テーマ第1弾リリース＋テーマ別LP
- UGCキャンペーン: `#おさんぽビンゴ` 投稿から毎週ベスト3を公式が紹介
- 数値を見て、伸びたチャネルにだけ広告費を投下
